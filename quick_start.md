# 快速启动（中文）
## 1. 通过 Prompt 启动
```
在 Hermes 输入如下提示词，让 Hermes 帮你启动：
请帮我安装并运行这个github项目，并把服务访问地址发给我：https://github.com/xmanrui/hermes-bot-review
```

## 2. 通过 Git 启动
```
git clone https://github.com/xmanrui/hermes-bot-review.git
cd hermes-bot-review
pnpm install
pnpm dev
```

## 3. 通过 Skill 启动
```
npx clawhub install hermes-bot-dashboard
或者：npx skills add xmanrui/hermes-bot-dashboard

安装后通过这些关键词触发启动服务：
- "打开 Hermes-bot-review"
- "打开 Hermes dashboard"
- "打开 bot review"
- "打开机器人大盘"
- "打开 bot-review"
- "打开hermes机器人大盘"
- "open hermes dashboard"
- "open Hermes-bot-review"
- "launch bot review"
- "start dashboard"

```

# Quick Start (English)

```
In Hermes, send the prompt below and let Hermes set it up:
Please help me install and run this GitHub project, and send me the service URL: https://github.com/xmanrui/hermes-bot-review
```

## 2. Install via Git
```
git clone https://github.com/xmanrui/hermes-bot-review.git
cd hermes-bot-review
pnpm install
pnpm dev
```

## 3. Install via Skill
```
npx clawhub install hermes-bot-dashboard
or: npx skills add xmanrui/hermes-bot-dashboard

After installation, use these trigger phrases to start the service:
- "打开 Hermes-bot-review"
- "打开 Hermes dashboard"
- "打开 bot review"
- "打开机器人大盘"
- "打开 bot-review"
- "打开hermes机器人大盘"
- "open hermes dashboard"
- "open Hermes-bot-review"
- "launch bot review"
```
